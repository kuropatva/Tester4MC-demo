Tester4MC is a library for automated functional system testing of Minecraft Spigot plugins in Java.

The library works by launching parallel instances of the server and simulating player connections using MCProtocolLib, then analyzing returned packets to verify plugin behavior.

[Demo](https://github.com/kuropatva/Tester4MC-demo/blob/master/src/test/java/targetTests/PlayerPointsTests.java)

Written for "Software testing" labs at WMiI, UJ
